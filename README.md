# 保利威网页开播直播 AI 助手

挂件目前只处理 **播放器封面** 和 **引导页直播封面**。用户可以对话生成图片、添加参考图、继续描述修改意见，并在确认定稿后上传到指定保利威频道。

## 启动

```bash
npm install
npm start
```

本机服务运行在 <http://127.0.0.1:8765/demo>。在线模式从 `.env.local` 读取百炼图片服务配置与保利威 API 凭据。`DEMO_MODE=1 npm start` 可运行离线演示，不会写入正式频道。参考图由出图模型直接使用；如果单独的截图理解接口不可用，生成流程仍会继续，并在对话里说明。

## 在正式频道唤醒

Chrome 或 Edge 的扩展管理页开启开发者模式，选择“加载已解压的扩展程序”，目录选本项目的 `extension/`。保持本机服务运行，复制 `.env.example` 为 `.env.local`，填写 `POLYV_CHANNEL_ID`、`POLYV_APP_ID` 和 `POLYV_APP_SECRET`。需要支持更多频道时，在 `POLYV_CHANNEL_IDS` 中用逗号分隔填写。打开任一已配置频道的保利威后台，点击浏览器工具栏的“保利威直播 AI 助手”图标。扩展会核对当前频道，并将定稿素材保存到当前频道。

修改扩展文件后，在扩展管理页重新加载扩展，再刷新频道页面。挂件的当前对话和“历史会话”保存在本机浏览器，并按频道区分；保存图片引起页面刷新后会自动恢复。点击“＋ 新对话”可开始另一轮创作，之前的对话可从“历史会话”打开。多个标签页的对话按会话分别保存，参考图的缩略图也会留在历史中。服务端同时将会话上下文保存在 `data/sessions/`，重启本机服务后仍可继续修改草稿。清除该浏览器的站点数据会移除浏览器中的历史列表。

正式频道保存成功后，页面会刷新以更新后台预览。扩展会记住挂件的展开状态，在页面重新加载完成后自动保持打开。

## 保存方式

播放器封面使用 `warmImage` 上传，保存到 `player.warmUpImageUrl`。引导页直播封面使用 `splashImage` 上传，保存到 `splash.splashImageUrl`。确认定稿后，服务端先读取当前装修配置，只替换选中的图片字段，再提交并回读核对。具体映射见 [API 说明](docs/polyv-api-fit.md)。

定稿需要明确的肯定指令和当前草稿版本；“不要定稿”“这张可以吗？”等不会触发保存。两个素材同时保存时会依次更新频道配置。本机写入接口只接受本机来源的 JSON 请求。

本项目是指定频道的黑客松原型，本机业务接口尚未接入用户权限校验，不应直接公开部署。

## 验证

`npm test` 检查对话、素材识别、出图规格、定稿和保利威接口字段映射。关键接口为 `GET /api/specs`、`POST /api/chat`、`GET /api/draft/:sessionId/:version`、`GET /api/state` 和 `GET /api/asset/:targetId`。
